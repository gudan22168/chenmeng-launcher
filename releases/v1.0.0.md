# 尘梦启动器 v1.0.0

首个正式发行版，面向 Windows x64。

- Microsoft 正版登录与离线模式。应用服务访问申请已通过，维护者已实测正版登录。
- Minecraft 与 Fabric / Forge / NeoForge 实例安装、下载源切换、Java 配置与运行设置。
- Modrinth 内容工坊、模组启用禁用、批量编辑、更新前备份与恢复、整合包导入导出。
- 世界手记、日志与崩溃诊断、可选 AI 分析。
- AI 模组语言翻译：术语表、批量翻译、增量补译，统一合并为一个资源包。
- 模组别名与精简界面、随窗口缩放简化的启动视图。

## 下载与升级
下载 ChenMeng-Launcher-1.0.0-portable.exe。SHA256SUMS.txt 可用于核对文件完整性。
关闭旧启动器后，将新 EXE 放在原启动器目录，保留原 .minecraft 文件夹。升级前建议备份存档。
AI 服务需自行配置，可能产生服务费用。发行包不包含用户的游戏数据、账户或 Key。

## 已知限制
部分 NeoForge 版本的下载问题仍需按版本排查，正式版编号不代表所有组合均已验证。
前置检查不能保证模组间不存在运行时冲突。
语言翻译仅支持可提取的标准 JSON 语言文本；旧翻译包没有原文记录时只补新增键。
当前 EXE 未进行代码签名。
