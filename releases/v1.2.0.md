# 尘梦启动器 1.2.0

- 新增 ZIP、RAR、Modrinth .mrpack 整合包导入，可选择文件或直接拖到窗口。RAR 解压组件内置，无需安装 WinRAR。
- 支持含版本配置的游戏目录包，识别原版、Fabric、Forge、NeoForge；保留模组、配置、存档等游玩文件。首次启动时检查并补全游戏和加载器。
- 新实例使用传统启动器风格的 .minecraft\versions\1.20.1 目录，资源与依赖库共享；旧实例保持原位置。
- 修复首页同步读取模组别名造成的等待，非首页页面和安装依赖按需加载。
- 修复整合包清单中的 mediafilez.forgecdn.net / edge.forgecdn.net 下载地址被误拦截，保留 HTTPS 和文件完整性校验。
- 后台解压支持取消；验证路径、重复文件、大小及数据完整性，失败时清理临时文件和未完成实例。

支持普通单文件 RAR4 / RAR5，包括固实压缩和中文路径。加密 RAR、分卷 RAR、7z、Quilt、CurseForge 仅清单包及旧启动格式暂不支持；多个独立版本需分别导入。压缩文件和总解压大小上限 2 GiB，单文件上限 256 MiB。

验证覆盖 ZIP/RAR 导入、标准路径、后台响应、取消和失败清理，以及打包后的文件选择和真实拖拽。尚未进行完整 Minecraft 下载和 Java 游戏实际启动验证。

建议下载 ChenMeng-Launcher-1.2.0-x64.zip，完整解压后运行“尘梦启动器.exe”。该版本无需每次启动自解压；首次使用可将原 .minecraft 文件夹放在程序旁。单文件 portable.exe 仍保留，但其自解压过程有额外启动等待。
