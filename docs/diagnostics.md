# 模组前置绕过、日志诊断和可选 AI

## 模组下载
正常依赖解析失败且属于找不到必需前置时，确认窗口提供“忽略前置，生成仅下载所选模组的清单”。它不直接下载，仍显示清单并要求确认。仅跳过 required 依赖遍历，保留游戏/加载器匹配、哈希校验、文件保护和显式不兼容声明检查。前置内置或需要手动安装时可以使用，不保证游戏一定能运行。

## 本地诊断
侧栏“诊断”按当前实例读取 launcher.log、launcher.previous.log、logs/latest.log、logs/debug.log、最近两份 crash-reports 和最近两份 hs_err_pid 日志。不跟随日志目录链接，单文件最多读取 256 KiB 首尾片段。启动失败或异常退出时自动切换到当前实例的诊断页。
本地规则覆盖 Java 版本/路径、内存、缺前置、重复模组、Mixin、显卡/OpenGL、原生崩溃、类库不匹配、磁盘权限和网络问题。命中只代表排查线索，日志时间可能属于不同运行。
导出 ZIP 含脱敏报告和有限日志片段，不含存档、账户配置或 AI 设置文件。分享前仍需自行检查。

## 可选 AI
设置页面提供 OpenAI 兼容 API 基础地址、Key、模型 ID、读取模型列表及连通检测。Key 通过 Electron safeStorage 加密后与地址/模型一起保存在本机 ai-settings.json 中；快照与导出不返回 Key。更换地址会清除旧 Key。
远程接口要求 HTTPS，本机 localhost/127.0.0.1/::1 可用 HTTP。请求禁止重定向，以免认证信息被带到其他地址。
API 合约为 GET /models 和 POST /chat/completions。仅列出模型不保证有调用权限。暂不支持仅提供 Responses/Anthropic 原生接口的服务。

发送前先提取错误上下文、去重、脱敏和限制长度，并提供可编辑报告。附加游戏/加载器/Java版本、内存、系统架构、显卡标识、模组清单和规则结果，不自动附加其他文件。需要勾选确认并在系统确认框中再次确认目标服务，取消时不发网络请求。模型结果以纯文本展示，启动器不自动执行命令或修改文件。

## 设置修正
全局下载源、版本隔离、窗口行为和 AI 设置不依赖当前实例存在。内存和 Java 选择只在有实例时显示。
