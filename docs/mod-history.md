# 模组启用、批量操作和备份恢复

- 启用/禁用通过 .jar 与 .jar.disabled 改名，不删除文件。保留原文件哈希和管理记录。
- 网上列表支持选择本页、清空和批量加入。已选版本优先；未选择时使用版本列表首项。仍须检查并确认才下载。
- 本地列表支持选择当前筛选结果、批量启用/禁用、加入所选更新和加入所选移除。更新需先“检查更新 / 前置”。更新/移除继续使用待处理清单。
- 启用/禁用和恢复前需先应用或放弃已有草稿，避免旧清单被误用。
- 每次模组安装、更新、移除、启用、禁用前，复制全部模组文件形成快照，含禁用文件、管理记录与 SHA-512 校验。更新文件先下载校验，再备份并提交。
- 备份位于实例 mod-backups/<编号>/files/mods；manifest.json 记录操作前后指纹。备份不含存档和配置，不会自动清理，可能明显增加磁盘占用。
- 只有已完成且对应当前实例/游戏/加载器/隔离目录的快照可列出恢复。旧版只有零散原文件的备份仍可手动提取。
- 当前模组必须与该次操作完成后的指纹一致，才能一键恢复；后续安装或手动改动会阻止覆盖。可以选择与当前状态匹配的历史快照，或手动提取。
- 恢复前验证备份完整性，并为当前状态新建快照；恢复失败时回滚文件和管理记录。恢复操作本身也可用新快照撤回。
- 内存中的批量操作不是崩溃恢复日志：进程被强制结束或断电时可能留下 prepared 快照或 rollback 目录，需要手动检查，不宣称整次操作具有断电原子性。
