# AI 模组语言翻译

入口：内容工坊 → 模组工作台工具栏 → AI 语言翻译。

支持搜索文件名、已知模组名称与自定义别名。勾选一个或多个模组（最多 100 个），选择源/目标语言，读取合并预览后提交翻译；最后统一导出到当前实例 resourcepacks/ChenMeng-Translations.zip。

- 术语表每行使用“原文=译文”，最多 200 项，保存在本机；翻译时作为数据发送给已配置 AI。
- 无标准 JSON 源语言时在本地提示并跳过，不发送 AI。这不等于证明硬编码：也可能没有界面文字、使用旧版 .lang 或内嵌资源。存在标准文件也不能证明全部文本都可翻译。
- 每批最多 30 条 / 约 5000 原文字符，当前预览最多 4000 条。已成功的批次保存草稿；失败停止，继续时只发送空白译文。AI 可能计费，每次请求前确认。
- 多个模组共用命名空间且同键内容冲突时拒绝合并，需分别处理。
- 合并包内记录导出时的原文。更新模组后重新读取，自动列出新增键与原文变化的键，变化条目展示旧译文供参考；确认导出后替换这些条目。未变化的译文保持不动。
- 旧版生成包没有原文记录，无法判断已有键的原文是否变化，因此只补新增条目，保留已有译文；不把旧译文自动当作过期译文。
- 不删除已经从模组移除的旧键，不改动模组 JAR，不自动启用资源包。游戏内手动启用合并包。
- 前一版 ZIP 保存在实例 translation-backups/ChenMeng-Translations.zip.previous；关闭游戏后可手动复制回资源包位置。
- 最近一次预览草稿存于 translation-work/draft.json。手动编辑请导出或提交翻译后再离开。

模组别名在模组信息中编辑，显示为“别名（原名）”；支持本地筛选和已登记别名的网络查询转换。设置可确认清除对照表。别名与术语表仅保存在本机启动器配置中。
