# 本地 Minecraft 导入与目录兼容

本轮新增扫描、复制导入和模组精简显示；尚未迁移现有 runtime/instances 布局。

## 扫描与导入
- 实例页“扫描并导入已有 Minecraft”默认扫描启动器数据目录的父目录及最多四层子目录，也可手动选择扫描位置。
- 识别 versions/<版本名>/<版本名>.json，解析继承及 Fabric、Forge、NeoForge 库坐标。
- 展示完整版本路径，允许选择隔离版本目录或共享根目录作为游玩数据来源，并在资源管理器打开确认。
- 不扫描当前启动器自身的数据目录；跳过链接、资源库、存档等大目录。扫描上限 3000 个目录和 500 个版本。
- 复制导入会新建隔离实例；原目录不修改。首次启动重新校验下载官方游戏和加载器。
- 复制 saves、mods、config、defaultconfigs、resourcepacks、shaderpacks、screenshots、kubejs、scripts、patchouli_books、journeymap、xaeroworldmap、xaerominimap、schematics 及游戏选项、服务器列表。
- 不复制旧启动器账户、Java 路径、自定义 JVM 参数和其他未列出的专用文件。定制客户端、Quilt、旧启动格式和无法可靠识别的配置显示原因，不猜测导入。
- 导入前关闭原游戏；共享目录的游玩数据可能属于多个版本，需自行确认。
- 失败时移除新建的未完成实例；暂存文件清理范围限定在本启动器 imports 目录。

## 模组显示
模组工作台新增精简显示开关，隐藏网上模组描述并减小行距，保留详情入口、图标、版本选择、拖放和加入操作。偏好保存在当前启动器的本地界面设置中。
“查中文名”只在浏览器中打开 MC 百科搜索，不抓取、翻译或自动对应 Modrinth 项目。

## 后续目录兼容
建议采用通用 assets/libraries/versions 布局，并将版本隔离目录放在对应版本下。迁移需要一起处理版本 JSON/JAR 命名、继承关系、加载器配置、游戏目录参数及旧实例映射；直接改文件夹名不足以保证其他启动器识别。应先验证迁移、回滚与其他启动器读取后再启用，不能据此宣称当前目录已兼容。
